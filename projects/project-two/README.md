# Project Two: Security Policy Presentation

## Overview

Project Two turned the Green Pace security policy into a narrated security presentation. The final presentation contains **19 slides** and explains how the different policies and secure-coding practices work together.

## Presentation Topics

- Defense in depth
- Threat matrix and risk prioritization
- Ten core security principles
- Ten C/C++ coding standards
- Encryption at rest, in flight, and in use
- Authentication, authorization, and accounting
- Google Test unit testing
- DevSecOps automation
- Static-analysis and testing tools
- Risks and benefits of acting now versus waiting
- Recommendations and future improvements

## Unit Testing Demonstration

For the unit-testing portion, I used a spray tank level that should only accept values from 0% through 100%.

The six tests were:

- 50% accepted
- 0% accepted
- 100% accepted
- -1% rejected
- 101% rejected
- 150% rejected

The final Visual Studio test run completed with **21 tests passed and 0 failed**.

## Automation Tools Discussed

- Microsoft C++ Code Analysis
- Cppcheck
- GitHub CodeQL
- Clang-Tidy
- Google Test
