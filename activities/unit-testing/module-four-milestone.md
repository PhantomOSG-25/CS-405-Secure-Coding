# Module Four Milestone: Unit Testing

The Module Four milestone focused on using unit tests to verify expected behavior and failure conditions instead of relying only on manual testing.

The original test project completed with **15 tests passed and 0 failed**.

Later, for Project Two, I expanded the same test project with six additional tank-level validation tests. That brought the final Test Explorer result to:

- **21 tests passed**
- **0 tests failed**
- **0 tests skipped**

This progression was useful because it showed how a test suite can grow as new security requirements are added. The six additional tests covered normal input, lower and upper boundaries, and invalid values on both sides of the allowed range.

The main lesson for me was that unit testing is not just about proving the program works when everything is correct. Negative tests are what prove the program knows when to say no.
